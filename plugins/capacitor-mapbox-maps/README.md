# @fresh2go/capacitor-mapbox-maps

Native **Mapbox Maps SDK** (Android v11) for the Capacitor driver shell.

> **v1 scope:** full-screen native map activity.  
> Embedded MapView-behind-WebView is phase 2.  
> Day-to-day driver home map still uses `mapbox-gl` via `DriverMapbox.tsx` until phase 2 ships.

## Why

- Capacitor `android-driver/` is **gitignored** (generated by `cap sync`).
- Native Mapbox cannot live only inside that folder; it must be a **Capacitor plugin** that sync copies in.
- `native-driver` already uses Mapbox Maps SDK natively; this plugin brings the same SDK into the Capacitor APK when needed.

## Install

Already wired in the monorepo:

```json
"@fresh2go/capacitor-mapbox-maps": "file:plugins/capacitor-mapbox-maps"
```

After `npm install`:

```bash
npx cap sync android   # with capacitor.driver.config.ts active
```

`scripts/build-apks.sh` also patches Mapbox Maven credentials into the generated Android project.

## Token

1. **Public token** (`pk.*`) — runtime map tiles (same as `VITE_MAPBOX_TOKEN`).
2. **Secret downloads token** (`sk.*` with `DOWNLOADS:READ`) — Gradle can fetch `com.mapbox.maps:android`.

Set for CI / local:

```bash
export MAPBOX_DOWNLOADS_TOKEN=sk.your_secret_downloads_token
```

Or `~/.gradle/gradle.properties`:

```
MAPBOX_DOWNLOADS_TOKEN=sk....
```

## Usage (TypeScript)

```ts
import { MapboxMaps } from '@fresh2go/capacitor-mapbox-maps';
import { Capacitor } from '@capacitor/core';

async function openNativeMap() {
  const { available } = await MapboxMaps.isNativeAvailable();
  if (!available || Capacitor.getPlatform() !== 'android') return;

  await MapboxMaps.initialize({
    accessToken: import.meta.env.VITE_MAPBOX_TOKEN,
  });

  await MapboxMaps.createMap({
    fullScreen: true,
    center: { lat: 39.665, lng: 20.8537 },
    zoom: 14,
    styleUri: 'mapbox://styles/mapbox/streets-v12',
    markers: [
      { id: 'store', lat: 39.67, lng: 20.85, title: 'Store' },
    ],
  });
}
```

## Build notes

Without `MAPBOX_DOWNLOADS_TOKEN`, Gradle cannot resolve `com.mapbox.maps:android` and the driver APK build will fail once this plugin is linked. The plugin is optional until you call `createMap` — keep the downloads token in CI secrets (same as `native-driver`).
