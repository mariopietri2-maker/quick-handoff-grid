# Fresh Delivery

Real-time food delivery marketplace connecting customers, restaurants, and drivers.

## Apps
- **Customer** (`/order`) — browse restaurants, order, track delivery
- **Driver** (`/driver`) — accept offers, navigate, handoff
- **Store** (`/store`) — manage menu, accept orders, print tickets
- **Admin** (`/admin`) — live ops, financials, fraud, analytics
- **Support** (`/support`) — tickets, customer/driver tools

## Stack
React 18 · Vite · TypeScript · Tailwind · shadcn/ui · Lovable Cloud (Supabase) · Mapbox · Capacitor (Android/iOS)
