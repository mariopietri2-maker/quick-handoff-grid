What Changed

REMOVED Left floating circle

The Navigation overview button (地图全览) that showed the full map has been removed. Drivers no longer need it since they use turn-by-turn navigation.

CHANGED Right circle → Support

The Crosshair recenter button has been replaced with a green Headphones support button. Tapping it opens the support dialog with 7 categories (Emergency, Order, Customer, etc.) and live ticket chat.

REMOVED Διάλειμμα (Break)

The break feature has been removed from the driver UI: the amber "Διάλειμμα" status pill, the break banner in the bottom sheet, and the break dialog in the UserMenu. The backend still supports it for admin/monitor views.
