# Day 4 — Driver offer (app open)

**Goal:** With driver app **open** and driver **online**, a new offer appears and alert plays.

## Setup
1. Install driver APK **1.0.3+**
2. Login as driver → go **online**
3. Keep app in **foreground**
4. Store accepts a cash order that needs a platform driver (or create test offer)

## Pass criteria
- [ ] Offer visible in driver UI without force-closing app
- [ ] Sound and/or vibration for new offer
- [ ] Can accept or reject offer

Background/screen-off is **Day 5**. Today only foreground.
