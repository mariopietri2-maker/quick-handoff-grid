# Play Console — Data safety answers (Fresh2GO Customer)

## Does the app collect or share user data?
**Yes**

## Data collected

| Data type | Collected | Shared | Purpose | Required |
|-----------|-----------|--------|---------|----------|
| Email address | Yes | No* | Account | Yes |
| Name | Yes | No* | Account / delivery | Yes |
| Phone number | Yes | No* | Account / delivery | Optional |
| Approximate location | Yes | No* | Delivery / nearby stores | Yes for delivery |
| Precise location | Yes | No* | Delivery address / tracking | Optional |
| App activity (orders) | Yes | No* | Fulfillment | Yes |
| Payment info | Via Stripe | Stripe | Payments | If paying by card |

\* Shared with restaurants/drivers only as needed to fulfill an order (not sold for advertising).

## Security practices
- Data encrypted in transit (HTTPS / TLS)
- Users can request deletion (account / support)
- Not primarily designed for children

## Sensitive permissions
- Location (foreground): delivery address, nearby stores
- Notifications: order status
