Fresh Delivery

Πλήρης επισκόπηση της πλατφόρμας — Web SPA + 2 εγγενείς εφαρμογές Android (Kotlin/Compose)

Web React + Vite Database Supabase (Postgres + RLS + Realtime) Native Kotlin / Jetpack Compose Χάρτες Mapbox Push Firebase Πληρωμές Stripe Εκδοχές Driver 2.6.0 / Customer 2.7.0
✨
Τι προστέθηκε σε αυτή τη συνεδρία

1) Τα μενού των καταστημάτων ενημερώνονται άμεσα στο customer app (realtime στο menu_items + live εγγραφές στη σελίδα εστιατορίου και στην αρχική).  2) Φωτογραφίες προϊόντων μόνο από admin (bucket item-images + DB trigger που μπλοκάρει μη-admin αλλαγές στο image_url).  3) Λευκός χάρτης Mapbox στο native driver app με διακόπτη στις Ρυθμίσεις (Λευκός / Σκούρος).
